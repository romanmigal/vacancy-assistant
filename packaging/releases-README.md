# Помощник по вакансиям — установщики

Программа для поиска работы. Вы добавляете вакансии с любых сайтов — ссылкой, сохранённой страницей или текстом; для ИТ она сама читает ленты Хабр Карьеры и GeekJob. Программа оценивает каждую по вашему резюме и критериям и помогает откликнуться: пишет сопроводительное письмо и сообщение знакомому в компании, показывает, чего не хватает резюме, готовит к собеседованию.

Работает на вашем компьютере, окно открывается в браузере. Вакансии разбирает языковая модель на выбор:

- **Gemma** через [Ollama](https://ollama.com) — на этом же компьютере, резюме и вакансии никуда не уходят;
- **GigaChat** (Сбер) — облачная модель для компьютеров, где локальная не тянет; резюме и вакансии уходят в Сбер;
- **без модели** — как трекер откликов: вакансии, статусы, этапы, контакты и статистика, без оценок и писем.

Программа ничего не отправляет за вас: не откликается и никому не пишет.

Здесь лежат только готовые установщики — по одному релизу на версию.

## Установка на Mac

**Проще всего — одной командой.** Откройте Терминал: Finder → «Программы» → «Утилиты» → «Терминал» (или Launchpad → поиск «Терминал») и вставьте:

```bash
curl -fsSL https://raw.githubusercontent.com/romanmigal/vacancy-assistant/main/packaging/install_mac.sh | bash
```

Команда скачает последнюю версию для вашего процессора, сверит контрольную сумму и поставит программу в «Программы» — без предупреждения macOS о неподписанной программе. Той же командой ставят обновления; данные при этом не трогаются. Что делает команда — [в скрипте](https://github.com/romanmigal/vacancy-assistant/blob/main/packaging/install_mac.sh).

Или вручную:

1. Откройте .dmg и перетащите «Помощник по вакансиям» в «Программы».
2. Программа не подписана у Apple (подпись платная), поэтому при первом запуске macOS её не пустит:
   - дважды щёлкните программу в «Программах» — появится предупреждение, нажмите «Готово»;
   - откройте «Системные настройки → Конфиденциальность и безопасность», внизу у строки про «Помощник по вакансиям» нажмите «Всё равно открыть» и подтвердите паролем;
   - запустите программу снова. Дальше она открывается обычным двойным щелчком.

## Установка на Windows

1. Запустите `VacancyAssistant-windows-setup.exe`. Права администратора не нужны.
2. Программа не подписана, поэтому Windows покажет окно «Система Windows защитила ваш компьютер»: нажмите «Подробнее» → «Выполнить в любом случае».
3. Дальше программа запускается из меню «Пуск» или ярлыком на рабочем столе.

## Первый запуск

Пошагово со снимками экрана — установка, ключ GigaChat, мастер профиля и первые вакансии: [гид «Первый запуск»](https://github.com/romanmigal/vacancy-assistant/blob/main/docs/%D0%9F%D0%B5%D1%80%D0%B2%D1%8B%D0%B9%20%D0%B7%D0%B0%D0%BF%D1%83%D1%81%D0%BA.md). Он же есть в программе: ссылка в заголовке мастера и «Параметры → Помощь».

Окно откроется в браузере. Если профиль у вас уже есть, мастер предложит загрузить архив экспорта с прежнего компьютера («Параметры → Резервная копия → Экспорт для переноса…») или выбрать папку, где профили уже лежат. Иначе он спросит о резюме, критериях и модели и создаст новый профиль.

- По умолчанию мастер предложит GigaChat: нужен только ключ GigaChat API — мастер подскажет, где его взять.
- Для локальной модели установите [Ollama](https://ollama.com/download) — нужно около 8 ГБ на диске, саму модель мастер скачает.

Ваши данные лежат в папке «Документы → Помощник по вакансиям»; другую можно выбрать в «Параметры → Настройки → Папка с данными». Закрыть программу — «Параметры → Выйти из программы».

## Обновления

Раз в день программа проверяет, нет ли здесь новой версии: простой запрос без данных о вас. Если есть — в окне появится ссылка на скачивание и «Что нового». Сама программа ничего не скачивает и не ставит: скачайте установщик и поставьте поверх — данные в «Документах» сохранятся. Проверить сразу — кнопка «Проверить обновления» в «Параметры → О программе». Автоматическую проверку можно выключить в «Параметры → Настройки → Обновления».
